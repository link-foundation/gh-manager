## Research and existing components

- [GitHub workflow job logs](https://docs.github.com/en/rest/actions/workflow-jobs#download-job-logs-for-a-workflow-run) redirect to short-lived plain-text downloads. The REST client needs a separate text reader; credentials must not be forwarded to the download host. Actions read permission is needed for private data.
- [Workflow dispatch](https://docs.github.com/en/rest/actions/workflows#create-a-workflow-dispatch-event) requires a dispatch-enabled workflow and Actions write permission. Keep support for the existing API version's empty dispatch response by discovering a newly created run; reruns must wait for a newer attempt, not consume the old completion.
- [Git trees](https://docs.github.com/en/rest/git/trees#get-a-tree) can truncate recursive responses. Traverse subtrees when truncated rather than silently dropping manifests.
- [Octokit](https://github.com/octokit/octokit.js) provides REST pagination/retries, but adding a second client would duplicate the injectable REST abstraction. Extend the existing client and reuse the project's pagination style.
- [libsodium sealed boxes](https://libsodium.gitbook.io/doc/public-key_cryptography/sealed_boxes) are already implemented through `libsodium-wrappers`; preserve them for both secret scopes.
- Existing `yaml` parsing avoids matching commented references; existing `pollUntil` provides finite polling with injected clocks; existing file glob utilities provide a starting point but file paths require slash-aware `*`/`**` behavior.
- Existing `setup-buildx-resilient` already implements bounded retries and a mirror. Its intentionally failing mock Docker output appears in passing test jobs and is not an additional live Docker outage.

## Reproduction and findings

The failed `Checks and release` run [37779097679](https://github.com/link-foundation/gh-manager/actions/runs/37779097679) is for main commit `f455df9`, created after that commit. Saved log line 10867 records the warning test taking 3217.795458 ms; line 11217 reports `Expected 124 to be 0`. The wrapper correctly killed work that exceeded its 3-second budget; the test's one-second headroom was the defect. The warning test now uses the issue's proposed 10/4/30 timings. Kill tests use a five-second budget and finite workers. No wrapper behavior was removed.

The failed `Example app` run [37779097805](https://github.com/link-foundation/gh-manager/actions/runs/37779097805) uses the same commit. Saved log line 1586 reports `[[: not found` under `sh -e`. Regression tests failed on the missing Bash default and on executing the existing summary script; both now pass with Bash and environment-supplied drift. BuildKit mock tests deliberately print Docker failures and pass; retry/mirror handling is already resolved in the composite action.

Before implementation, the source-boundary test failed on the policy map/functions, and fallback tests failed with organization HTTP 403 instead of writing repository secrets. Those regression tests now pass. Additional fixtures verify every new CLI command, both health outcomes and unknown evidence, both dispatch/rerun paths, delayed revocation across multiple repositories, access-only updates, pagination and truncated trees.

## External scope and release prerequisites

The upstream [shared template](https://github.com/link-foundation/js-ai-driven-development-pipeline-template/blob/main/tests/run-with-budget-warning.test.js) contains the same timing case. [template-timing.patch](template-timing.patch) updates its warning/kill tests and finite worker lifetimes. It is supplied for upstream application; it has not been pushed to a sibling repository because this task permits pushes only to the prepared gh-manager branch.

The package lookup returns E404 and `npm whoami` returns ENEEDAUTH. The reviewed bootstrap plan selects the prepared branch, `release.yml`, and the GitHub Actions trusted publisher. Publication and publisher registration require a package-owner browser login/2FA; no stored publishing token is introduced. [npm's trust documentation](https://docs.npmjs.com/cli/v11/commands/npm-trust/) confirms that the package must exist before its publisher can be configured. The authorized bootstrap execution and current-head CI results are recorded in the PR when completed.

[Picomatch](https://github.com/micromatch/picomatch) is an available alternative for full Bash-style glob syntax. This implementation follows the repository's small glob API, adding slash-aware `*`, `?`, and `**` for file paths; those supported forms are documented. Adding brace/extglob syntax is a separate expansion, not required by the manifest/workflow use cases supplied in these issues.
